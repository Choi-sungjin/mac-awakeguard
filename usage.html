🦉 mac-awakeguard

커버를 덮거나 화면을 잠가도 로컬 Gateway가 가능한 한 계속 작동하도록 돕는 macOS 메뉴 막대 앱입니다.

중요한 안전 한계

목표는 커버를 덮어도 Gateway가 작동하도록 유지하는 것입니다.

앱은 Gateway Guard를 기본으로 켜고 유휴 절전 방지를 요청합니다. 다만 배터리 상태의 닫힌 덮개, 가방 안 발열, 하드웨어 sleep 같은 macOS 안전 정책은 우회하지 않습니다.

설치 방법

  1. GitHub Releases에서 최신 mac-awakeguard.app.zip을 다운로드합니다.
  2. 압축을 풉니다.
  3. HeraAwakeGuard.app을 ~/Applications 또는 /Applications로 옮깁니다.
  4. Finder에서 앱을 엽니다.

macOS가 실행을 막으면 시스템 설정 → 개인정보 보호 및 보안 → Open Anyway를 선택하세요.

xattr -dr com.apple.quarantine ~/Applications/HeraAwakeGuard.app
open ~/Applications/HeraAwakeGuard.app

실행 후 위치

Dock 아이콘은 보이지 않습니다. macOS 상단 메뉴 막대에 🦉 상태 아이콘이 표시됩니다.

앱 ~/Applications/HeraAwakeGuard.app 또는 /Applications/HeraAwakeGuard.app

로그 ~/Library/Logs/HeraAwakeGuard.log

언제 쓰나

  • 로컬 개발 서버를 오래 켜두고 싶을 때
  • 커버를 덮어도 Hermes Gateway가 가능한 한 계속 작동해야 할 때
  • Hermes Gateway, Paperclip, 데이터베이스, 대시보드 같은 localhost 도구를 유지하고 싶을 때
  • AI 에이전트, 빌드, 다운로드, 긴 스크립트가 유휴 절전으로 중단되지 않게 하고 싶을 때
  • 화면은 꺼두거나 잠금 상태로 두되 작업은 계속 돌리고 싶을 때

메뉴 사용법

시간 선택

메뉴 막대 아이콘을 클릭한 뒤 1시간부터 25시간까지 원하는 시간을 선택합니다.

무한 유지

직접 끄기 전까지 유휴 절전 방지를 요청합니다. 전원과 통풍이 확보된 상태에서 사용하세요.

Gateway Guard

앱 실행 시 기본으로 켜집니다. 유휴 절전 방지를 유지하면서 로컬 Hermes Gateway와 Paperclip 상태를 점검해 커버 닫힘 상황에서도 Gateway 유지 가능성을 높입니다.

끄기 · 원래 상태

앱이 만든 power assertion을 해제하고 macOS 기본 절전 동작으로 되돌립니다.

잠금 화면으로 전환하고 끄기

잠금 화면으로 전환하기 전에 awake 상태를 해제합니다.

종료

앱을 종료하고 assertion을 해제합니다.

동작 확인

pmset -g assertions | grep -i "Awake Guard"

정상일 때: 앱이 활성화된 동안 power assertion 항목이 보입니다.

권장 운영 패턴

  • 커버 닫고 Gateway 유지: AC 전원 연결, 책상 위 통풍 확보, Gateway Guard 활성 상태를 권장.
  • 가장 안정적인 닫힌 덮개 운영: AC 전원 + 외부 디스플레이/키보드/마우스가 있는 공식 clamshell 조건.
  • 배터리 + 가방 이동: 발열과 macOS sleep 정책 때문에 Gateway uptime 대상으로 보지 않습니다.
  • 항상 외부 접속 필요: 고정 Mac, NAS, VPS, 클라우드 서버가 더 안정적입니다.
