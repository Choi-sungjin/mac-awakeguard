🦉 Hera Awake Guard

MacBook Air에서 Hermes Gateway와 Paperclip을 가능한 한 안정적으로 유지하기 위한 귀여운 올빼미 메뉴바 앱입니다.

중요한 안전 한계

덮개를 닫고 배터리 상태로 가방 안에서 계속 온라인 상태를 유지하는 것은 macOS가 보장하는 안전 동작이 아닙니다.

이 앱은 열 안전, 배터리 보호, clamshell 정책을 우회하지 않습니다. 가방 안 상시 구동은 발열 위험이 있어 권장하지 않습니다.

설치 위치

앱 /Users/sungjin/Applications/HeraAwakeGuard.app

Finder 별칭 바탕화면의 Hera Awake Guard

소스 /Users/sungjin/Projects/HeraAwakeGuard

로그 /Users/sungjin/Library/Logs/HeraAwakeGuard.log

실행 방법

  • Finder에서 /Users/sungjin/Applications/HeraAwakeGuard.app를 더블 클릭합니다.
  • 또는 바탕화면의 Hera Awake Guard 별칭을 더블 클릭합니다.
  • 터미널에서는 아래 명령을 사용할 수 있습니다.
open /Users/sungjin/Applications/HeraAwakeGuard.app

실행하면 Dock에는 보이지 않고, macOS 상단 메뉴바에 🦉 Hera가 표시됩니다.

메뉴 사용법

시간 선택

메뉴바의 🦉 Hera를 클릭하거나 우클릭한 뒤 시간 선택에서 1시간부터 25시간까지 고를 수 있습니다.

무한 유지

직접 끄기 전까지 깨어 있도록 요청합니다. 덮개가 열린 상태 또는 안전한 clamshell 조건에서 사용하세요.

Gateway Guard

깨어 있음 assertion을 유지하면서 Hermes Gateway와 Paperclip 상태를 주기적으로 점검합니다.

끄기 · 원래 상태

Hera가 잡은 전원 유지 assertion을 해제해서 macOS 기본 절전 동작으로 되돌립니다.

잠금 화면으로 전환하고 끄기

잠금 화면을 띄우기 전에 Hera Awake 상태를 해제합니다. 메뉴를 쓰지 않고 Control + Command + Q로 잠금 화면에 들어가도 세션 비활성 이벤트를 감지해 원래 상태로 돌립니다.

종료

앱을 종료하고 assertion을 해제합니다.

권장 운영 패턴

  • 책상 위 장시간 운영: 전원 연결, 통풍 확보, 가능하면 덮개 열림 상태 유지.
  • 닫힌 덮개 운영: AC 전원 + 외부 디스플레이/키보드/마우스가 있는 공식 clamshell 조건에서만 권장.
  • 가방 이동: 앱을 켜도 macOS가 잠들 수 있습니다. 발열 때문에 상시 구동을 권장하지 않습니다.
  • 항상 외부 접속이 필요하면: 고정 Mac, NAS, VPS, 또는 클라우드 Hermes Gateway가 더 안정적입니다.

상태 점검 명령

pmset -g assertions | grep -i "Hera Awake Guard"
launchctl print gui/$(id -u)/ai.hermes.gateway-hera | egrep 'state =|pid =|runs ='
launchctl print gui/$(id -u)/ai.paperclip.default | egrep 'state =|pid =|runs ='
curl http://127.0.0.1:3100/api/health

정상일 때: power assertion에 Hera Awake Guard가 보이고, gateway/paperclip은 running, Paperclip health는 ok입니다.
